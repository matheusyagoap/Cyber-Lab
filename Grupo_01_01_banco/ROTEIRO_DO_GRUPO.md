# Roteiro da equipe — Nexa Bank

1. Crie um repositório GitHub para a equipe e envie **somente esta pasta**.
2. Abra o repositório e crie um Codespace.
3. No terminal, execute `pip install -r requirements.txt`.
4. Execute `python app.py`. A aplicação usa a porta **5301**.
5. Abra a aba **Portas** e acesse a porta encaminhada.
6. Em outro terminal, execute `python scanner.py`.
7. Analise `relatorios/relatorio.json` e `relatorios/relatorio.pdf`.
8. Implemente a tarefa descrita em `DESAFIO.md`.
9. Rode o scanner novamente e registre a comparação antes/depois.
10. Entregue JSON, PDF, código e justificativa ao professor.

Não teste sistemas externos. Use somente o ambiente local deste cenário.
