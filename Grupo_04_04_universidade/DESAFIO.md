# Campus One — Desafio CyberLab

## Contexto
Você foi contratado como consultor(a) para avaliar a aplicação fictícia **Campus One** (Plataforma de gestão acadêmica). O ambiente contém somente dados sintéticos e deve ser testado exclusivamente no Codespaces deste laboratório.

## Objetivo
Investigar controles de acesso, exposição de informações e configuração de segurança. Execute `python scanner.py`, examine as evidências em `relatorios/relatorio.json` e `relatorios/relatorio.pdf` e valide os indicadores manualmente.

## Tarefa de programação
['Visão acadêmica', 'Alunos', 'Disciplinas', 'Histórico escolar']

## Dica
A correção deve ocorrer no backend. Não confie em identificadores enviados pelo navegador. Faça a autorização antes de serializar ou devolver o registro.

## Entrega
1. Relatório inicial (JSON e PDF). 2. Código alterado. 3. Evidência do teste antes/depois. 4. Breve justificativa técnica.
